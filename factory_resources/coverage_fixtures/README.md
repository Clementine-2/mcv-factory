# 覆盖率测试集

阶段 A.1。**这是覆盖率的唯一证据来源。** 不要再用「大约 99%」这种句子。

规则：

1. 每条是一句真人会说的需求，不是框架名。
2. 必须填得出 `PROJECT_SPEC`（至少 work_products / language / execution）。
3. `new_kind: false` 表示不得为此发明新的项目种类。
4. 失败 = ontology 缺轴或缺取值，而不是「再加一个框架」。
5. 组合栈必须拆轴，禁止一条需求对应一个新 Profile 名。

语料：`corpus.yaml`（当前 120 条）。还不是统计抽样，是**代表集**：常见、组合、以及故意设的陷阱。
