# Forward Roadmap After P4

This roadmap is serial. Only one major stage is active at a time.

## P5 — Semantic Intake & Decision Kernel

Replace the deterministic normalizer as the sole user-facing interpreter with an optional LLM semantic adapter governed by P1 contracts. Promote the bootstrap formula into a real versioned Formula/Policy decision engine without allowing it to execute work.

## P6 — Harness Compatibility & Process Integration

Prove the same generated project contract works with at least Codex and Claude Code. Evaluate Spec Kit as an upstream process integration/bundle component without modifying its core.

## P7 — Upstream Compatibility Lab

Automate `latest / tested / supported` qualification, Golden Project compatibility runs, provider version admission and safe dependency-update evidence.

## P8 — Generated Project Upgrade & Migration

Implement explicit project upgrade planning: analyze -> dry-run -> diff -> recovery point -> apply -> verify -> new lock. No silent mutation.

## P9 — Extension Ecosystem

Make Formula, Profile, Policy, Skill and Provider additions independently versionable/discoverable without Core edits. Keep arbitrary code execution boundaries explicit.

## P10 — Interactive Host Compatibility

Validate optional GUI/host paths such as AionUI/ACP while keeping them peer entry points rather than dependencies of the Factory or Runner.

## P11 — Long Runtime

Evaluate Dagu or another mature workflow/process supervisor as the `long_running_execution` Provider. Audit the old AgentRunner for reusable contracts, not presumed reusable implementation.

## P12 — Productization & Dogfood Hardening

Turn the development repository into the intended base-station user experience: distributable Factory package, bootstrap/doctor, clean first-run flow, recovery UX, documentation, real-project dogfooding and release gates.

## P-infinity — Continuous evolution

New project families, Formulas, Skills, providers and compatibility updates continue after the finite core roadmap. They do not justify reopening Core architecture without evidence.
