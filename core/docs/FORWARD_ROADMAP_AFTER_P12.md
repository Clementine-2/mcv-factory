## P∞ default work categories

- Profiles for additional native project families

## Conditions for reopening Core architecture

A new Core stage requires all of:

1. a reproduced real-world failure or recurring framework tax;
2. evidence that current Profile/Formula/Skill/Policy/Provider/Adapter/Extension surfaces cannot solve it without distortion;
3. a bounded proposal with rollback and compatibility impact;
4. explicit approval before implementation.
