# Forward Roadmap after P9

Completed: P0-P9.

## P10 - Interactive Host Compatibility

Validate that GUI/interactive Hosts remain peer entrypoints rather than dependencies of Factory. Target AionUI/ACP-style integration through stable project/Harness contracts. Hosts must not become the owner of Factory extensions.

## P11 - Long Runtime

Revisit the old AgentRunner problem as a capability/provider question. Audit reusable contracts, test mature orchestration providers such as Dagu where appropriate, and keep scheduling/process lifecycle outside project semantics and Factory Core.

## P12 - Productization & Dogfood Hardening

Turn the engineering kernel into the daily-use base-vehicle factory: bootstrap/doctor, first-run UX, safe distribution, real-project dogfood, release gates, failure recovery, documentation and packaging hardening.

## P-infinity - Continuous Evolution

Core should stabilize. Growth should mainly occur through Profiles, Formulas, Skills, Providers, domain extensions, Golden Projects and compatibility evidence rather than repeated Core rewrites.
